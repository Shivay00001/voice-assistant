# Ultra Advanced AI Assistant

A comprehensive voice-activated assistant capable of performing 500+ tasks including file management, system control, web automation, media capture, and productivity enhancements.

## Features

- **File Operations**: Create, delete, rename, search, organize, and zip files.
- **System Control**: Shutdown/restart, monitor CPU/RAM, manage volume/brightness.
- **Window Management**: Minimize/maximize, snap windows, launch apps.
- **Web Automation**: Search engines, social media, media streaming services.
- **Mouse & Keyboard**: Simulate typing, mouse movements, clicks, and scrolling.
- **Media Capture**: Take screenshots, screen recordings, and access webcam.
- **Productivity**: Timers, alarms, Pomodoro, notes, todo lists.
- **AI Features**: Context memory, learning capabilities, text manipulation.

## Usage

Run the script and speak commands to interact with the assistant.

```bash
python voice_assistant.py
```

## Dependencies

- `pyautogui`
- `speech_recognition`
- `pyttsx3`
- `psutil`
- `opencv-python`
- `pillow`
